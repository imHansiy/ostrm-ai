# 网盘页加载性能实测

测量日期：2026-11-16。正式站 `https://pan.007666.xyz/cinema/library`，桌面 Chrome 无头模式，1440×1000 视口，正常网络，不限速。默认非成人页，1,214 条视频、51 页。已登录，不含输入密码的时间。使用 Playwright 与 Chrome DevTools Protocol 记录可见海报、首张真实封面和可视区域 12 张图片解码完成的时间。数值是当前环境的单次实测，非任意网络下的保证。

| 场景 | 海报列表出现 | 首张真实封面 | 可视区域封面完成 |
|---|---:|---:|---:|
| 优化前：新浏览器、旧目录内存缓存已过期 | 13.90 秒 | 16.64 秒 | 20.81 秒 |
| 优化前：同一浏览器刷新 | 1.91 秒 | 4.04 秒 | 8.53 秒 |
| 优化后：新浏览器 | 2.17 秒 | 2.19 秒 | 3.21 秒 |
| 优化后：同一浏览器刷新 | 0.96 秒 | 0.98 秒 | 0.99 秒 |
| 优化后：影院重启，再用新浏览器访问 | 2.59 秒 | 2.62 秒 | 3.89 秒 |
| 优化后：影院重启后同一浏览器刷新 | 0.64 秒 | 0.66 秒 | 0.67 秒 |

“新浏览器”使用独立上下文并禁用浏览器 HTTP 缓存；优化后的服务端使用生产功能自身维护的目录、封面持久缓存和启动预热。首次全新部署、尚未建立任何缓存时需要先读取源数据，不等同于日常的浏览器首次打开。重复浏览及程序重启都可复用缓存。

优化后的首屏直接随经过登录验证的私有 HTML 返回，该采样没有额外的目录接口请求。目录后台更新、私有图片缓存及 ETag 不改变 TiDB 中的标签与任务数据，也不移动原视频或同目录的封面。少数原源返回 404 的封面仍使用缺图占位，不计作真实封面加载成功。

验证覆盖 660 项单元测试、生产构建、桌面与手机、明暗主题、匿名访问隔离、成人/非成人、全库筛选排序与分页、真实视频播放。重启验证只终止归属影院守护进程的 Node 子进程，由现有守护自动恢复；OpenList、AI 与 Java 服务保持运行。缓存权限检查为文件 0600，且没有附加常驻扫描进程。
